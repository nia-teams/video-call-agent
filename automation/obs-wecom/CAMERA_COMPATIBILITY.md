# 企微摄像头菜单版本兼容

旧版：在一对一视频通话窗口右上角，展开摄像头图标旁的小下拉箭头，选择 `OBS Virtual Camera`。

新版（如企微 5.0.13）：将鼠标移入视频区显示控制栏，再悬停摄像头按钮约 1 秒。不要短按或长按摄像头按钮，以免关闭视频。

## 校准 5.0.13

该版本的按钮没有可操作的辅助功能控件。使用默认 360×640 的一对一通话窗口，保持接通并显示控制栏。从已获得辅助功能和屏幕录制权限的终端运行：

```bash
npm run camera:calibrate
```

提示后 8 秒内切回企微，将鼠标停在摄像头按钮中心。看到「已保存新版摄像头按钮定位」后，`automation/obs-wecom/.build/` 中会有 `camera-button.json`（窗口内相对位置）和 `camera-button.png`（28×28 的按钮区域模板）。这些文件只保存在本机。

## 自动选取与验收

启动器使用已确认的通话窗口 ID，显示控制栏并核验客户端版本、窗口尺寸和按钮图像。控制栏位置变化时，在窗口下方的控制区查找唯一匹配的图标。版本、尺寸或外观变化而无法核验时，按日志提示重新校准；多个候选窗口、窗口关闭或用户移动鼠标时停止选择。

设备菜单未暴露辅助功能菜单项时，使用 macOS Vision 在本机识别文字，只选择唯一完整匹配的 `OBS Virtual Camera`。匹配用截图在本机临时处理后删除。图标定位及菜单识别最多等待 60 秒，处理阶段写入 `.runtime/media-studio/one-click.log`；挂断、停止启动器或新通话替换旧通话时取消选择。

先确认 OBS 已启动虚拟摄像头。菜单选中后，核对企微本地预览和 OBS 画面；确认对端是否收到需另行验证。
