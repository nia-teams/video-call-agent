# 新 Mac 安装与权限清单

适用于 macOS 14.2 及以上的 Video Call Agent。先按[项目说明](../README_CN.md#配置)创建 `.env`，准备自己的 OBS 和 Qwen 配置。以下命令在项目根目录执行。

## 1. 安装依赖

- [ ] 用普通账号执行 `npm run setup`，无 Node/npm 时运行 `bash ./install-dependencies.sh`。若弹出 Xcode Command Line Tools 安装提示，安装后重新执行。
- [ ] 仅在 Homebrew 或驱动安装提示时授予管理员权限。安装驱动会重启 CoreAudio，请先结束通话和录音。
- [ ] 确认 `npm run setup:check` 的必装项通过。这是依赖检查；后续仍须完成系统授权和通话测试。

## 2. 登录图形桌面

- [ ] 登录实际运行服务的 macOS 账号和官方企业微信客户端，保持桌面解锁、电脑唤醒。SSH 无法代替供通话界面使用的图形桌面。
- [ ] 后续从同一已授权的终端启动。改用 iTerm、VS Code 等应用时，检查实际启动应用的权限；测试时让企微通话窗口保持在前台。

## 3. 授权辅助功能

- [ ] 先运行一次 `npm start` 触发权限请求。在「系统设置 → 隐私与安全性 → 辅助功能」启用启动应用；若列表单独显示 `CameraSwitch`，按系统请求授权。没有终端条目时用 `+` 添加。
- [ ] 按提示退出并重开终端，然后重启项目。以日志显示「持续监控一对一通话」、监控未退出为准；「自动接听已开启」只表示开关状态。

## 4. 授权屏幕和系统音频采集

- [ ] 在「隐私与安全性 → 屏幕录制」授权启动应用；新版 macOS 可能显示「屏幕与系统音频录制」。若 `WeComCapture` 单独出现在列表中，按提示授权。
- [ ] 无授权条目时，在控制台点击「读取企微窗口」触发请求。授权后退出并重开对应应用、重启采集服务，确认能列出企微窗口且通话中的画面和音频接收计数增长。参见 [Apple 权限说明](https://support.apple.com/guide/mac-help/control-access-screen-system-audio-recording-mchld6aa7d23/mac)。

## 5. 允许 OBS 相机扩展

- [ ] 打开 `/Applications/OBS.app`，完成或跳过首次向导，再点一次「启动虚拟摄像机」触发扩展授权。
- [ ] **macOS 14**：「系统设置 → 隐私与安全性 → 安全性」，对被阻止的 OBS 系统软件点「允许」。**macOS 15 及以后**：「通用 → 登录项与扩展 → 相机扩展」，启用 OBS；必要时展开「按类别」。密码或 Touch ID 由用户确认。
- [ ] 重启 OBS 并启动虚拟摄像机，确认按钮变为「停止虚拟摄像机」。若企微在扩展启用前已打开，结束通话后重启企微以刷新设备列表。
- [ ] OBS 只使用项目浏览器源时，无需额外开启屏幕录制、麦克风或输入监控权限。项目也不需要完全磁盘访问权限。

## 6. 授权应用使用摄像头和麦克风

- [ ] 在「隐私与安全性 → 麦克风／摄像头」允许企业微信。Chrome 枚举音频设备或测试实体麦克风时按提示授予麦克风权限；只有使用实体摄像头作为网页来源时才需要给 Chrome 摄像头权限。
- [ ] 若系统要求重启应用，先结束当前通话。确认企微可使用摄像头和麦克风，系统声音设置列出 **Node Audio Send** 输出和 **Node Virtual Mic** 输入。

## 7. 授权 Chrome 站点并启用播放

- [ ] 在 Chrome 打开[控制台](http://127.0.0.1:3070/)，只保留一个控制台标签页。点击「授权并刷新音频设备」并允许本站麦克风访问。若拒绝过，从地址栏左侧打开网站设置，把麦克风改为「允许」后刷新。
- [ ] 设备名出现后，将 Qwen 输出设为 **Node Audio Send**。若 Chrome 阻止自动播放，点击一次「连接 Qwen」启用播放，再测试自动连接。站点麦克风授权与[浏览器自动播放策略](https://developer.chrome.com/blog/autoplay/)是两项独立检查。

## 8. 核对 OBS、Qwen 和音频选路

- [ ] 若 OBS 已运行，从「工具 → WebSocket 服务器设置」开启服务及密码认证。端口（默认 `4455`）和密码须与 `.env` 一致。执行 `npm run obs:status` 检查连接。
- [ ] 执行 `npm run env:check` 检查配置，并确认 [Qwen](../media/QWEN.md) 账号有权使用所选模型与音色。
- [ ] 企业微信和 macOS 默认麦克风选 **Node Virtual Mic**，企微扬声器与 macOS 默认输出选实体耳机或扬声器以防回声。若企微没有麦克风菜单，设好系统默认输入后重新建立通话。用控制台「检查企微实际音频设备」核对客户端实际使用的设备。

手动布置 OBS 时，在当前场景添加 [浏览器源](http://127.0.0.1:3070/studio/output)（修改 `PORT` 后同步 URL）。基础画布、输出和浏览器源都设为 **1080×1920**，可用 30 FPS。将来源置顶并保持可见，关闭「不可见时关闭源」「场景变为活动状态时刷新浏览器」和「通过 OBS 控制音频」。启动虚拟摄像机并确认预览；若媒体服务尚未启动，启动后刷新来源。

## 9. 定位新版企微摄像头按钮

- [ ] 在一对一测试视频中确认 OBS 预览已有数字人画面，通话窗口可见。旧版从右上角小箭头进入设备列表；新版悬停视频区后再悬停摄像头按钮约一秒。
- [ ] 企微 5.0.13 首次自动选摄像头前，按[定位指南](../automation/obs-wecom/CAMERA_COMPATIBILITY.md)在默认 360×640 窗口运行 `npm run camera:calibrate`。提示后 8 秒内将鼠标停在摄像头按钮中心，等待「已保存新版摄像头按钮定位」。按钮外观、窗口尺寸或客户端变更后重新定位。

## 10. 重启并验收通话

- [ ] 应用权限变更后，退出并重开受影响的应用。执行 `npm stop` 和 `npm start`；若媒体服务由另一个终端单独启动，也在该终端重启。`npm run start:check` 可分别检查设备、辅助功能和 OBS。
- [ ] 请知情的测试方拨入一对一视频。让启动器完成接听、采集、选摄像头和模型连接，检查接收计数、输入电平、数字人口型和本地预览；由对端确认收到画面和语音。
- [ ] 挂断后确认采集和模型会话都结束，再拨一通确认能重新连接。

## 排障

| 现象 | 检查项 |
| --- | --- |
| 未接听，日志显示监控退出 | 实际启动应用的辅助功能权限、可用的图形桌面和自动接听开关 |
| 已接听但未采集，或日志出现 TCC 拒绝 | 屏幕与系统音频权限；授权后重启进程；核对自动采集开关及窗口，必要时手动采集 |
| 控制台没有设备名或 Qwen 卡在音频初始化 | 系统和站点麦克风权限；刷新设备、点击「连接 Qwen」启用播放，关闭重复标签页 |
| OBS 摄像头扩展未激活、`code signature invalid` 或 `OSSystemExtensionErrorCode 8` | 按系统版本检查扩展授权。停止启动器，核对是否使用官网稳定版 OBS 和 Mac 支持的最新正式版，按 [OBS 官方排障](https://obsproject.com/kb/virtual-camera-troubleshooting)重新安装或授权；仍失败时记录 macOS、OBS 版本及错误日志 |
| OBS 预览正常，企微无画面或选错摄像头 | 核对来源 URL、可见性和层级，以及一对一通话中的实际设备。新版检查校准及窗口是否被遮挡 |
| OBS 或 Qwen 鉴权失败 | 核对服务开关、端口、密码、API Key、模型和音色访问权限 |
| 对端听不到回复、回声或啸叫 | 确认企微输入和控制台输出按第 8 步选路且话筒未静音；用控制台检测虚拟话筒输入电平。实体耳机可避免扬声器回授 |

安装日志位于 `.runtime/install-dependencies/`，通话启动日志位于 `.runtime/media-studio/one-click.log`。分享日志前移除密钥和通话内容。

若 npm 报 `EACCES` 或缓存含 root 所有的文件，安装器会使用独立缓存。单独重装依赖时也可指定临时缓存，不使用 `sudo npm ci`：

```bash
npm ci --include=dev --cache "$(mktemp -d "${TMPDIR:-/tmp}/video-call-agent-npm.XXXXXX")"
npm run setup:check
```

若错误路径在 `node_modules`，检查目录的所有权和写权限并关闭其他 npm 安装进程。应用下载失败时，可从 [OBS](https://obsproject.com/download)、[Chrome](https://www.google.com/chrome/)、[企业微信](https://work.weixin.qq.com/) 官网下载并安装到 `/Applications` 后重跑安装器。若终端找不到 npm，使用安装完成时打印的 `export PATH=...`，或在安装了 nvm 的终端运行 `nvm use`。
