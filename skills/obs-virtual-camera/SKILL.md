# OBS 虚拟摄像头

## 目标与边界

配置用户指定的 OBS 画面，将企微一对一视频通话的摄像头切换为 `OBS Virtual Camera`。保留已有场景和来源；用户未指定新内容时沿用正常输出，首次无可用来源时询问用户。

使用当前会话可用的桌面操作、截图和辅助功能工具。没有桌面操作工具时，告知用户需要能控制图形桌面的环境。

由用户建立和结束测试通话；本技能只设置视频，不拨号、接听、挂断、直播或录制。虚拟摄像头只发送画面，声音走单独的音频链路。

## OBS 输出与扩展

- 打开 `/Applications/OBS.app`，检查当前场景预览。使用视频文件时，添加「媒体源」，通过文件选择器选取文件并按需求循环播放，再将来源「变换 → 适配屏幕」。使用其他来源时，只申请该来源需要的权限。
- 点击「启动虚拟摄像机」。首次提示启用 OBS 官方相机扩展时，按系统版本操作：
  - macOS 13／14：「系统设置 → 隐私与安全性 → 安全性」，允许 OBS 系统软件。
  - macOS 15 及以后：「系统设置 → 通用 → 登录项与扩展 → 相机扩展」，启用 OBS；需要时在「按类别」下展开相机扩展。
- 管理员密码或 Touch ID 由用户确认。授权后重新打开 OBS 并启动虚拟摄像机，确认预览有画面，按钮变为「停止虚拟摄像机」。

## 切换企微摄像头

- 确认当前窗口是已接通的一对一视频通话。没有通话窗口时，先完成 OBS 设置，请用户建立测试通话。
- 用当前截图确认摄像头控件位置，并结合实时辅助功能树定位菜单；控件隐藏时先将鼠标移入视频区。以当前界面为准，不复用固定坐标或控件索引。
- 旧版：展开通话窗口右上角摄像头图标旁的小下拉箭头。
- 新版（如 5.0.13）：先悬停视频区，等控制栏出现，再悬停摄像头按钮约 1 秒，直至设备列表展开。只悬停，不点击或长按摄像头按钮，以免关闭视频。
- 在设备列表选中 `OBS Virtual Camera`，等待预览载入。若列表没有 OBS，检查扩展开关及虚拟摄像机。若企微先于扩展启用就已打开，等通话结束后再重启企微并检查列表。

## 验收标准

- OBS 预览显示所选内容，虚拟摄像机正在运行。
- 企微选中 `OBS Virtual Camera`，且通话中的**本地预览**显示同一画面；不要用对端大画面或切换时短暂出现的头像判断。
- 如果只确认了菜单选择，报告「已选择，画面尚未验证」。本地预览一致后报告「本地预览已验证」；对端是否收到需另行确认。
